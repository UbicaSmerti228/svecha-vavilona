# Свеча в Вавилоне

Пиксельная инди-игра по мотивам «Вавилонской библиотеки» Борхеса. Мальчик со свечой бродит по бесконечной библиотеке и ищет девять страниц о том, как он сюда попал. В темноте живут Лихо Одноглазое, Сирин и Астерион: они боятся огня, но свет их и приманивает.

## Как запустить

Открой `index.html` в браузере. Игра работает и на компьютере, и на телефоне. Если включить GitHub Pages (Settings → Pages → ветка `main`), игра будет доступна по ссылке.

## Управление

| Компьютер | Телефон | Действие |
|---|---|---|
| WASD / стрелки | джойстик слева | ходить |
| Shift | слабый наклон джойстика | красться тихо |
| E / пробел | большая кнопка | спрятаться в нишу, взять книгу, прочитать |
| F | «свеча» | задуть или зажечь свечу |
| Q | «вспышка» | отпугнуть тех, кто рядом (стоит воска) |
| G | «бросить» | бросить книгу-приманку |
| J | «Дневник» | обрывки, бестиарий, записки |

Графика: [three.js](https://threejs.org) r128 с cdnjs.
